# Reminder Commons fork

Source: https://github.com/SimpleMobileTools/Simple-Commons commit `b7dd6ad428fdaa72362ce04cc1dbfa407f4c2fa8`. GPL-3.0, see LICENSE.

Built from source instead of the published binary. Removed package-prefix restrictions that incorrectly label Reminder a fake app, block customization or bypass normal Storage Access Framework requests. Reminder is recognized as the full app. Android permission checks remain active. Build uses root plugins, isolated dependency catalog and local rtl-viewpager.
